StayFix — PG Complaint Management System

A simple and user-friendly PG Complaint Management System built with a Node.js Express API and Vanilla JavaScript frontend.

Features
Complaint Management: Submit, view, update, and delete complaints.
Complaint Details: Add resident name, room number, category, description, priority, and date.
Form Validation: Validates complaint details before submission.
Clean UI: Simple and responsive interface for easy complaint management.
Technologies Used

Frontend: HTML5, CSS3, Vanilla JavaScript
Backend: Node.js, Express.js, REST API
Data: JSON file storage
Testing: Postman
